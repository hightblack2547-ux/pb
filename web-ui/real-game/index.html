ORIGINAL WEBPORT ENGINE / OFFLINE ASSET CHECK

Point Blank Webport

หน้านี้จะเปิด Game Client ตัวจริงของ LeandroDettmer (Three.js + Rapier) โดยไม่พาไปฉาก FPS จำลองของเรา โปรแกรมจะตรวจไฟล์แผนที่ ปืน และตัวละครที่ได้รับอนุญาตก่อนเริ่มเกม

นี่ไม่ใช่ Point Blank ทางการ และไม่ได้มีไฟล์ Zepetto รวมมาให้ การดาวน์โหลดโค้ด MIT จาก GitHub ไม่ได้ทำให้มีสิทธิ์เผยแพร่ Assets ของเกม

กำลังตรวจ Assets บนเว็บไซต์…

โหมดเดินสำรวจใช้ไฟล์แผนที่ 3D และ Collision จริงที่คุณนำเข้า ไม่ใช่การแข่งขัน Point Blank และยังไม่ใช้โมเดลปืน/ตัวละครในเกม

ยังไม่ผ่านการตรวจไฟล์เกม

เกี่ยวกับระบบ

โหมดนี้เป็นการฝึกออฟไลน์กับบอทของ Webport ไม่ใช่ระบบห้องออนไลน์ ส่วน Login, Lobby และ Multiplayer ของ Webport ต้องมี Node.js Server + PostgreSQL เพิ่มเติม ซึ่ง Netlify แบบ Static เพียงอย่างเดียวไม่รองรับ
